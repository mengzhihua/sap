# SAP 演示系统技术方案

这是一套可运行的 SAP 风格 ERP 演示，覆盖 MM、SD、FI、CO、PP。它不是 SAP 官方产品。IR 把它当作库存、采购和生产订单的执行端。

## 1. 运行位置

单机和与控制塔同机都是后端 `8085`。Open IR 请求头 `X-Api-Key`，种子键 `sap-open-key`。登录业务口使用 `admin / admin123`。

## 2. 主链路

```text
采购申请 → 采购订单 → 收货 MIGO → 发票 MIRO
销售订单 → 交货 → 发货过账 → 开票
生产订单 → 发料 → 报工 → 完工入库
财务凭证与未清项随业务过账产生
```

SRM 走 OData 风格入站。BMS 走开放推送。这些链路不经过 IR。

`POST /api/open/events/goods-receipt` 按采购订单收货，同一参考号的 101 凭证重复推送返回原凭证。`POST /api/open/events/delivery` 按 OMS 订单号做发货过账，不要求事先有销售订单，同一外部单号重复推送返回原交货单。密钥默认 `sap-open-key`。

## 3. 控制塔读

`GET /api/open/ir/snapshots` 的 `snapshots` 行：

| dataType | 业务键 | 状态含义 |
| --- | --- | --- |
| `STOCK` | 物料/工厂/库存地点 | 非限制库存低于 10 记为 `LOW` |
| `PR` | 采购申请号 `banfn` | 申请状态 |
| `PO` | 采购订单号 `ebeln` | 订单状态 |
| `MO` | 生产订单号 `aufnr` | 订单状态 |
| 财务未清 | 应收/应付未清项 | 随 `appendOpenFi` 写入 |

没有 Key 时，控制塔改拉 `/api/mm/stock`、应收应付未清项和 `/api/dashboard/summary`。

## 4. 控制塔写

| 指令 | 专用口 | 作用 |
| --- | --- | --- |
| `SAP_CREATE_PR` | `POST /api/open/ir/create-pr` | 按物料和工厂建采购申请。业务键可用 `sku` 或 `matnr` |
| `SAP_RELEASE_PR` | `/release-pr` | 按 `banfn` 释放采购申请 |
| `SAP_RELEASE_MO` | `/release-mo` | 按 `aufnr` 释放生产订单 |

统一口是 `POST /api/open/ir/actions`。专用口在统一口缺失时由控制塔回退，请求仍带 `idempotencyKey`。

没有 API Key 时，控制塔登录后：

- 建申请：`POST /api/mm/pr`，抬头 `requester=IR`，行上带物料、数量、工厂
- 释放申请：`POST /api/mm/pr/{banfn}/release`
- 释放生产订单：`POST /api/pp/orders/{aufnr}/release`

## 5. 边界

控制塔不在这里过账 FI 凭证，也不代替 MM 收货。演示数据里的物料号要能在本系统主数据中找到，否则建申请会按本系统校验失败。
