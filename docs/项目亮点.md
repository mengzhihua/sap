# SAP 演示系统亮点

这是一套可运行的 SAP 风格 ERP，用来把采购、库存、销售、生产和财务凭证串起来。它不是 SAP 官方产品。

1. **过账会同时动库存和凭证。** 收货、发货、开票、总账过账不是各记各的表，业务单据和 FI/CO 凭证一起变。
2. **模块按事务覆盖主流程。** 采购申请到发票校验，销售订单到发货过账和开票，生产订单从释放到完工入库，固定资产做到月度折旧，总账有过账期间控制。
3. **外部系统有各自的入口。** 供应商系统按 OData 风格写入采购数据，结算系统推送仓储和订单单据并回写对账。
4. **控制塔能建单和释放，不能代替过账。** 创建采购申请、释放采购申请、释放生产订单走开放指令；没有密钥时走采购和生产登录口。收货、发货和财务凭证仍在本系统里做。
5. **进入方式贴近事务代码。** 可以从启动台进功能，也可以按事务代码进，演示时不用先记一套自造菜单名。
